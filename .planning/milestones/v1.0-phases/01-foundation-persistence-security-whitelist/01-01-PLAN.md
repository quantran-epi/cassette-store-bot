## Phase Goal

**As an** admin/shop owner, **I want to** run a secured Telegram bot backed by SQLite that recognizes whitelisted users and rejects strangers with their User ID, **so that** only authorized staff can manage customer and order data.

<objective>
Setup project build specifications, environment settings management using Pydantic-Settings v2, and the Telegram bot application factory with an access control whitelist security gate running at Handler Group -1.

Purpose: Provide robust local configuration loading (CFG-01) and security enforcement (SEC-01) preventing unauthorized users from accessing shop features while showing their Telegram User ID for easy onboarding.
Output: Working `pyproject.toml`, `src/config.py`, `src/bot/security.py`, `src/bot/app.py`, `src/bot/handlers/base.py`, and automated unit test suite.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Telegram Cloud → Bot Webhook/Polling | Untrusted external updates (messages, callback queries, commands) from any Telegram user cross here |
| Environment / Config → Application | Local .env file and environment variables containing bot token and API keys |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Spoofing | `src/bot/security.py` | mitigate | Telegram Bot API cryptographically authenticates sender ID; `whitelist_gate` strictly matches `update.effective_user.id` against in-memory whitelist set |
| T-01-02 | Tampering | `src/config.py` | mitigate | `Pydantic-Settings` validates types strictly at startup; invalid integer IDs or malformed configs fail-fast with clear errors |
| T-01-03 | Information Disclosure | `src/config.py` | mitigate | `SecretStr` wraps `telegram_bot_token` and `nine_router_api_key` so tokens never leak in string representations or audit logs |
| T-01-04 | Elevation of Privilege | `src/bot/app.py` | mitigate | `TypeHandler(Update, whitelist_gate)` registered at `group=-1` with `raise ApplicationHandlerStop()` halts unauthorized updates before any application handlers at group 0 run |
| T-01-SC | Tampering | Dependency packages | mitigate | PyPI legitimacy audit completed (all packages >2-8 yrs old, >500k-50M downloads/wk); versions pinned in `pyproject.toml` |
</threat_model>
