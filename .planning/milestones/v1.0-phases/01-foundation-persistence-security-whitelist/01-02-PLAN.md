## Phase Goal

**As an** admin/shop owner, **I want to** store customer profiles with multiple phone numbers, delivery addresses, and notes in an async SQLite database, **so that** customer contact history is preserved reliably without database lock stalls.

<objective>
Implement the asynchronous SQLite persistence layer using aiosqlite with WAL mode configuration, and build the Customer domain model and database repository supporting multi-phone and multi-address JSON arrays.

Purpose: Fulfill DATA-01 by providing structured customer profile storage without complex multi-table joins, while enforcing robust async SQLite concurrency via WAL mode (D-03, D-05, D-07).
Output: Working `src/db/connection.py`, `src/db/schema.py`, `src/models/customer.py`, `src/db/customers.py`, and comprehensive test suite.
</objective>
