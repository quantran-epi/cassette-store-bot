  <name>Task 1: Add _get_active_db_context helper in search.py and broaden is_search_intent in order_search.py</name>
  <files>src/bot/handlers/search.py, src/services/order_search.py</files>
  <behavior>
    - Test 1: `is_search_intent("a Biên đã mua băng bao giờ chưa nhỉ?")` returns True.
    - Test 2: `is_search_intent("anh Nam mua mấy đơn rồi?")` returns True.
    - Test 3: `is_search_intent("chị Mai có mua băng bao giờ chưa?")` returns True.
    - Test 4: `is_search_intent("Khách Tuấn 0903123456 2 cuốn Tuấn Vũ 200k")` returns False (keeps order ingestion intact).
    - Test 5: `process_search_query` executes successfully when `context.application.bot_data["db"]` is None by resolving connection via `_get_active_db_context`.
    - Test 6: `handle_search_callback` detail navigation (`sch_v`) executes successfully when `context.application.bot_data["db"]` is None.
  </behavior>
  <action>
1. In `src/bot/handlers/search.py`:
   - Import `contextlib.nullcontext` and `src.db.connection.get_db_connection`.
   - Implement `_get_active_db_context(context: ContextTypes.DEFAULT_TYPE)` matching the pattern in `src/bot/handlers/orders.py` and `src/bot/handlers/callbacks.py`:
     Extract `db` from `app_context.db` or `context.application.bot_data.get("db")`. Extract `db_path` from `settings.sqlite_db_path` or fallback to `"cassette_store.db"`. Return `nullcontext(db) if db else get_db_connection(db_path)`.
   - In `process_search_query`:
     Remove strict check `if not openai_client or not settings or not db:` and replace with checking `if not openai_client or not settings:`.
     Acquire db connection with `async with _get_active_db_context(context) as active_db:` and pass `active_db` to `run_order_search`.
     If `active_db` is None or unavailable, log error and send polite failure message.
   - In `handle_search_callback` (inside `sch_v` block):
     Replace `if not db:` with `db_ctx = _get_active_db_context(context)` and `async with db_ctx as active_db:`, then call `await get_order_by_id(active_db, order_id)`.

2. In `src/services/order_search.py`:
   - Define compiled regex or tuple of conversational inquiry patterns for Vietnamese search intent:
     Patterns covering:
     - Questions ending with: `bao giờ chưa`, `chưa nhỉ`, `chưa bác`, `chưa ad`, `chưa shop`, `không nhỉ`, `được không`
     - Questions containing: `đã mua`, `từng mua`, `mấy đơn`, `bao nhiêu đơn`, `lịch sử mua`, `tra cứu`, `tìm kiếm`, `kiểm tra`
     - Whitelist question keywords: `có mua ... không`, `bao giờ chưa`
   - In `is_search_intent(text: str) -> bool`:
     Check both `any(trimmed.startswith(prefix) for prefix in SEARCH_PREFIX_KEYWORDS)` AND regex/keyword search for conversational inquiry patterns.
     Ensure order creation text with customer phone numbers or order drafts (e.g. text containing 10-digit phone number and order items) is NOT falsely flagged unless it explicitly contains search intent markers.
  </action>

  </verify>

`src/bot/handlers/search.py` safely executes searches with dynamic DB fallback when `bot_data["db"]` is None, and `is_search_intent` correctly identifies conversational inquiry questions without breaking order creation.
