## 3. Cross-Phase Integration & E2E Flows

Integration checker subagent validated 22 active exports across phase boundaries:
- **Flow 1 (Free-text Ingestion → Confirmation → Persistence):** Text or photo caption parsed via LLM, staged in `user_data`, confirmed via `ord:cf:<id>`, customer and order snapshot persisted into SQLite with customer history.
- **Flow 2 (Order Ingestion Media Group Debounce):** Multi-photo albums debounced (500ms), highest resolution file IDs aggregated into a single order draft.
- **Flow 3 (Daily List → Detail Card → Status Change & Copy):** 2x2 keyboard opens date picker, renders order list card, drill-down to detail card with `CopyTextButton`, status transitions update DB in-place.
- **Flow 4 (Natural Language Search → Confirmation → Detail):** Direct conversational query or `[🔍 Tra cứu đơn]` triggers Text-to-SQL search, returns single suggestion or paginated multi-results, preserves search back-navigation.
- **Flow 5 (Security Gate & Routing Isolation):** Whitelist gate at Group -1 intercepts and halts non-whitelisted users before Group 0 handlers run.
