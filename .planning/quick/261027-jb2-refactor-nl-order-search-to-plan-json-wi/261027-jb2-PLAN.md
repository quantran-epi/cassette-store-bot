<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User query → LLM planning prompt | Free text bọc trong `<query>`, có thể chứa chỉ dẫn giả |
| LLM JSON plan → SQLite | SQL và purpose do model sinh; SQL chạy trực tiếp nếu qua validate |
| LLM purpose → Telegram HTML | Purpose là untrusted model output, ghép vào card HTML |
| Aggregate rows / list rows → summary prompt | Rows có thể là dữ liệu khách hàng; list rows không được gửi |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
