# Quick Task 261027-m8x: LLM Mutation Flow Refactoring & Static Order Edit

## Objective
1. Thêm tính năng sửa đơn static qua menu nút bấm và nhập liệu từng trường không qua LLM.
2. Tái cấu trúc luồng chat mutation LLM thành 2 phase: Phase 1 dùng LLM Text-to-SQL tìm đơn đích (tránh bắt nhầm từ khoá như 'Hà' vs 'Hà Nội'), Phase 2 bóc tách delta có context đơn cũ (`<current_order>`) để giữ nguyên các phần thông tin không đổi.

2. **Task 2: Mutation Search & Context-aware Delta**: LLM SQL generator tìm đơn cần sửa, refactor `handle_mutation_flow` và `handle_mutation_selection` để truyền `<current_order>` vào `extract_mutation_delta`.
3. **Task 3: Tests & Verification**: Viết test cho static edit, mutation search, context-aware delta merge.
