## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Telegram callback -> bot | `help:*` do client gửi lên, có thể bị sửa số trang/kind tuỳ ý |
| Nội dung tĩnh -> HTML message | Nội dung viết cứng, render qua `parse_mode="HTML"` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-261027-E01 | Tampering | `handle_tutorial_callback` | mitigate | Chỉ nhận `^help:page:(-?\d+)$` và `^help:try:([a-z_]+)$`; `int()` trong try/except; kẹp `0 <= n < PAGE_COUNT`. Không nhận chuỗi callback thô. |
| T-261027-E02 | Elevation of Privilege | `help:try:<kind>` | mitigate | `TRY_ACTIONS` là dict whitelist kind -> callback đích; kind lạ chỉ `query.answer()` rồi return. Client không truyền được callback đích tuỳ ý. |
| T-261027-E03 | Injection | text render | mitigate | Nội dung là hằng số tĩnh, không nội suy input người dùng; chỉ nội suy số trang đã kẹp. |
| T-261027-E04 | Spoofing | truy cập tutorial | accept | `whitelist_gate` group -1 đã chặn mọi Update từ người lạ. |
</threat_model>
