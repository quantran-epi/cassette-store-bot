<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Free-text natural language query → LLM translation | Untrusted Vietnamese user text is sent to LLM to produce SQL. |
| LLM-generated SQL → SQLite Database engine | LLM-generated query is executed against the production database. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Tampering | `src/services/order_search.py::sanitize_and_validate_sql` | high | mitigate | Strictly enforce single-statement (reject any semicolon), verify statement starts with SELECT, reject any DDL/DML token (`INSERT`, `UPDATE`, `DELETE`, `DROP`, `ALTER`, `CREATE`, `REPLACE`, `ATTACH`, `PRAGMA`), enforce `LIMIT 20`. |
| T-04-02 | Elevation of Privilege | `src/services/order_search.py::build_text_to_sql_prompt` | medium | mitigate | Enclose user query within `<query>...</query>` tags in user turn; system prompt strictly dictates read-only SELECT behavior and restricts table scope to `orders` and `customers`. |
| T-04-SC | Tampering | npm/pip/cargo installs | high | mitigate | package-legitimacy gate: no new packages added in this phase; only verified existing packages used. |
</threat_model>
