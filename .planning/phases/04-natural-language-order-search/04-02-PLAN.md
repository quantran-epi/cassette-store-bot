<objective>
Implement the Telegram search UI, 2-phase confirmation workflow, context-preserving navigation, and dual-trigger routing for natural language order search.

Purpose: Provide an ergonomic, elderly-friendly Telegram interface where users can trigger searches via 2x2 keyboard or natural text, preview matching orders with explicit confirmation before opening sensitive details, and smoothly navigate back to search results without losing context.
Output: Search cards and keyboards in `src/bot/keyboards.py`, search handlers in `src/bot/handlers/search.py`, menu and routing updates in `src/bot/app.py`, `src/bot/handlers/ingest.py`, and `src/bot/handlers/orders.py`.
</objective>
