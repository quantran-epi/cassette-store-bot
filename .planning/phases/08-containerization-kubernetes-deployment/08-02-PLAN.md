# Plan 08-02: Multi-stage Dockerfile, .dockerignore & Docker Compose Setup

<objective>
Build an optimized, multi-stage Docker container for the bot on `python:3.12-slim` running as non-root user `appuser` (UID 10001) with `TZ=Asia/Ho_Chi_Minh`, configure strict `.dockerignore` to prevent secret/database leaks, and produce a production-ready `docker-compose.yml` with persistent named volume `/app/data`, health check, and graceful shutdown policy.
</objective>

<threat_model>
- **Threat Ref:** T-08-01 (Container Breakout & Host System Compromise)
- **STRIDE:** Elevation of Privilege
- **Impact:** Attacker exploiting a vulnerability in Python dependencies gains root access to the host machine.
- **Mitigation:** Enforce non-root execution (`USER 10001:10001`) in Dockerfile. Dedicated `appuser` owns only `/app` and `/app/data`.
- **Threat Ref:** T-08-02 (Secret & Database Leak in Container Image)
- **STRIDE:** Information Disclosure
- **Impact:** Building Docker image inadvertently packages local `.env`, SQLite databases (`*.db`, `*.db-wal`), or backup files into image layers pushed to public registries.
- **Mitigation:** Comprehensive `.dockerignore` file explicitly excludes `.git`, `.env*`, `*.db*`, `backups/`, `.venv/`, and `__pycache__/`.
</threat_model>

<task id="08-02-02">
  <name>Implement optimized multi-stage Dockerfile</name>
  <read_first>
    - pyproject.toml
    - .planning/phases/08-containerization-kubernetes-deployment/08-RESEARCH.md
    - .planning/phases/08-containerization-kubernetes-deployment/08-PATTERNS.md
  </read_first>
  <action>
    Create `Dockerfile` in root directory with multi-stage architecture:
    1. **Stage 1 (builder):**
       - Base: `python:3.12-slim`
       - Set `PIP_NO_CACHE_DIR=1`, `PIP_DISABLE_PIP_VERSION_CHECK=1`
       - Install build dependencies (`gcc`, `build-essential`) via `apt-get` with cleanup
       - Copy `pyproject.toml` and install dependencies into `/install` prefix:
         `pip install --prefix=/install .`
    2. **Stage 2 (runtime):**
       - Base: `python:3.12-slim`
       - Environment:
         - `PYTHONUNBUFFERED=1`
         - `PYTHONDONTWRITEBYTECODE=1`
         - `TZ=Asia/Ho_Chi_Minh`
         - `PATH="/install/bin:$PATH"`
         - `PYTHONPATH="/install/lib/python3.12/site-packages:$PYTHONPATH"`
         - `SQLITE_DB_PATH=/app/data/cassette_store.db`
       - Install `tzdata` and configure timezone link, purge apt cache
       - Create non-root user and group: `groupadd -g 10001 appgroup && useradd -u 10001 -g appgroup -s /bin/bash -m appuser`
       - Copy `/install` from builder stage
       - Set `WORKDIR /app`
       - Create persistent volume mount directory: `mkdir -p /app/data /app/data/backups && chown -R appuser:appgroup /app`
       - Copy application code: `COPY --chown=appuser:appgroup src/ ./src/` and `COPY --chown=appuser:appgroup main.py ./`
       - Switch to `USER 10001`
       - Add container `HEALTHCHECK`:
         `HEALTHCHECK --interval=30s --timeout=5s --start-period=15s --retries=3 CMD ["python", "-m", "src.scripts.healthcheck"]`
       - Command: `CMD ["python", "main.py"]`
  </action>
  <acceptance_criteria>
    - `Dockerfile` exists and has `FROM python:3.12-slim AS builder` and runtime stage
    - Uses non-root user UID 10001 (`USER 10001`)
    - Configures `TZ=Asia/Ho_Chi_Minh`
    - Creates `/app/data` with ownership for appuser
    - Contains `HEALTHCHECK` executing `python -m src.scripts.healthcheck`
  </acceptance_criteria>
</task>
