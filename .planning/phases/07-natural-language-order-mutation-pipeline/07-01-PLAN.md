## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Telegram Chat → Intent Router | Untrusted raw text messages cross into intent classification and regex |
| LLM Gateway → Mutation Extractor | External LLM output crosses into Pydantic schema validation |
| Application → SQLite WAL | Concurrency updates and audit log entries cross into persistent storage |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Tampering / Prompt Injection | `src/services/intent_router.py` | mitigate | Use regex fast-paths first; enclose text in `<message>...</message>` tags and restrict LLM output to 5 max_tokens with zero temperature |
| T-07-02 | Elevation of Privilege | `src/services/mutation_extractor.py` | mitigate | Strict Pydantic schema validation for `OrderMutationDelta`, enforcing `ge=0` on amounts, phone regex normalization, and enum containment for `OrderStatus` |
| T-07-03 | Denial of Service | `src/db/orders.py::find_orders_for_mutation` | mitigate | Limit query results to 5 records maximum and sanitize keyword queries with unaccent function |
| T-07-SC | Tampering | npm/pip installs | mitigate | Zero external package installs; all dependencies already verified in virtual environment |
</threat_model>
