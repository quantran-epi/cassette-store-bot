    1. Define constants `VN_TZ = zoneinfo.ZoneInfo("Asia/Ho_Chi_Minh")` and `JOB_BACKUP_NAME = "daily_database_backup"`.
    2. Implement `schedule_daily_backup(app: Application, time_str: str = "02:00") -> None`:
       - Retrieves `app.job_queue`. If `None`, returns.
       - Iterates over `jq.get_jobs_by_name(JOB_BACKUP_NAME)` and calls `job.schedule_removal()` per Pitfall 4.

       - If `stats["is_oversized"]`: sends red alert message to `super_admin_id` with size and server path `stats['gz_path']` per D-09.

       - Formats caption per D-06: timestamp (UTC+7), uncompressed MB vs compressed MB, reduction %, order count, and customer count.
       - Calls `send_backup_document` to `super_admin_id`. If `False`, sends alert message per D-10, D-12.
    4. In `_do_sync(app, db, settings)`, load `backup_time = await get_setting(db, "backup_schedule_time", default="02:00")` and call `schedule_daily_backup(app, backup_time)` per D-14, D-15.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Telegram Client ➔ /backup Command & Callbacks | Any Telegram user can attempt to invoke administrative backup commands |
| Admin Text Input ➔ Scheduler Time & User Names | Untrusted text input from chat is parsed and saved to database settings |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-04 | Elevation of Privilege | `/backup` & `adm:bkp:*` handlers | mitigate | Protected by `@require_role(UserRole.SUPER_ADMIN)` check at handler entry. Regular admins receive alert popup; unauthorized users are rejected |
| T-06-05 | Information Disclosure | Telegram Document Destination | mitigate | Document upload destination is strictly pinned to calling Super Admin user ID for `/backup` or `settings.telegram_super_admin_id` for JobQueue |
| T-06-06 | Denial of Service / Crash | Background JobQueue Exception | mitigate | Nightly job callback is enclosed in comprehensive `try...except Exception`, logging stacktrace to ring buffer and sending Telegram alert without interrupting bot loop |
| T-06-07 | Tampering | Backup Schedule Time String | mitigate | Input string validated against strict regex `^([01]\d|2[0-3]):([0-5]\d)$` before updating database or rescheduling JobQueue |
</threat_model>
