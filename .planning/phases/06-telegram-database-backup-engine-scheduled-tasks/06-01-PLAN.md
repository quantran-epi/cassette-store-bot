<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Application Service ➔ File System (`backups/`) | File path creation and retention unlinking crosses file system boundary |
| Application ➔ Telegram Bot API | Outbound multipart document transfer containing SQLite database snapshot |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Tampering | `execute_backup` snapshot path | mitigate | Snapshot and archive paths are generated strictly from sanitized ISO timestamps (`ts = now.strftime('%Y%m%d_%H%M%S')`), preventing path traversal into external directories |
| T-06-02 | Denial of Service | `backups/` storage exhaustion | mitigate | Immediate `try...finally` unlinking of raw uncompressed `.sqlite3` file and automatic pruning retaining strictly the 7 newest archives |
| T-06-03 | Denial of Service | Telegram Bot API 50MB upload limit | mitigate | Enforce `SAFE_SIZE_LIMIT = 48 * 1024 * 1024` (48MB). Upload is rejected before calling Telegram API if size exceeded per D-09 |
| T-06-SC | Tampering | Package dependencies | mitigate | Stdlib `gzip`, `shutil`, `zoneinfo` utilized with zero third-party packages added |
</threat_model>
